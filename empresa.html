Serviço de SMS

Usa o app SMS Gateway for Android com o Local Server ligado no celular. O site fala com o gateway por meio de um servidor Node.js (server.js) que roda no seu computador, na mesma rede do celular.

Iniciar o servidor local

1. Instale o Node.js (nodejs.org). 2. Baixe o server.js e salve em uma pasta. 3. Abra o terminal nessa pasta e rode o comando abaixo. Deixe a janela aberta enquanto usar a agenda.
